# 메인 화면 최종 디자인 적용

## 변경 범위
- `src/routes/index.tsx`만 수정합니다.
- H1, 소제목, 안내 상자, 보조 문구, 상담 시작 버튼 순서를 요청대로 재배치합니다.
- 기존 `/questionnaire` 이동과 Compass 아이콘은 유지합니다.
- 공통 스타일, 공통 Button, 문진·결과 화면은 변경하지 않습니다.

## 디자인 적용
- 흰 배경과 중앙 정렬 단일 컬럼, 1120px 전체 컨테이너와 720px 읽기 영역을 적용합니다.
- 지정된 타이포그래피, 민트 구분선, 회색 안내 상자, 전체 너비 단색 민트 버튼을 해당 페이지의 Tailwind 클래스에서만 구현합니다.
- 추가 헤더·푸터·이미지·아이콘·문구는 만들지 않습니다.

## 검증
- TypeScript 검사를 실행합니다.
- 브라우저에서 `/`만 데스크톱 1440×1000과 모바일 390×844로 확인합니다.
