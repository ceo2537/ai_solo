# 영양나침반 3화면 리디자인 및 연결

## 구현 범위
- 홈(`/`), 문진(`/questionnaire`), 결과(`/result`)만 승인된 콘셉트에 맞춰 재구성하고 하나의 상담 흐름으로 연결합니다.
- 전역 디자인 토큰과 한국어 문서 설정을 적용하며, 외부 AI·저장소·DB·URL 파라미터는 사용하지 않습니다.
- 결과는 입력값과 승인된 근거를 이용한 안전한 Phase 1 데모로 한정합니다.

## 화면별 변경
- **공통**: 조용한 텍스트 로고, 1120px 컨테이너, Pretendard/Noto Sans KR, 지정 색상·16px radius·shadow, 일관된 버튼/입력/카드/포커스 상태를 적용합니다. `prefers-reduced-motion`을 존중합니다.
- **홈**: 기존 정보 구조를 유지하면서 2열 hero와 코드 기반 건강·나침반 라인 일러스트를 구현하고, CTA를 문진으로 연결합니다. 모바일에서는 1열로 재배치합니다.
- **문진**: 기존 검증·오류 포커스·초기화·질환 선택 규칙을 유지합니다. 숫자 입력은 데스크톱 3열, 모바일 1열로 만들고, 선택 상태에 체크 표시를 추가합니다. 유효 제출 시 입력을 모듈 메모리에만 기록하고 결과로 이동합니다.
- **결과**: 입력 요약, 우선 확인 항목, 출처가 연결된 본문형 영양성분/생활습관 안내, 안전 안내를 구성합니다. 데이터가 없으면 만료 안내와 새 상담 시작만 보여줍니다. 상담 종료는 메모리를 비우고 홈으로 이동하며, 다시 생성은 상태를 유지합니다.

## 기술 세부사항
- `src/styles.css`에 문서의 토큰을 정확히 등록하고 semantic Tailwind 유틸리티로 사용합니다.
- `src/routes/__root.tsx`의 `lang`과 공통 head/font 설정을 한국어 서비스에 맞게 정리합니다.
- 별도 브라우저 저장 없이 작은 client-safe 모듈이 현재 탭의 런타임 메모리에서만 문진 데이터를 보관합니다.
- 새 `/result` 라우트에 고유 title/description/Open Graph 메타데이터를 추가합니다.
- 모든 개별 조언의 `출처`는 승인된 2025 한국인 영양소 섭취기준 링크로 연결하고, 진단·치료·개인별 정확 섭취량 표현은 넣지 않습니다.

## 검증
- TypeScript 검사와 빌드 상태를 확인합니다.
- Playwright로 1440px, 768px, 390px에서 홈 → 문진 → 유효 입력 → 결과 → 상담 종료 흐름을 검증합니다.
- 문진 오류 범위, `없음` 상호 배타, 초기화, 직접 `/result` 접근 만료 상태, 모바일 가로 넘침, 콘솔/런타임 오류를 함께 확인합니다.
